# NOIR® Streetwear

**Not made for everyone.**

NOIR® is a streetwear e-commerce concept built to explore bold visual design, responsive layouts, and interactive shopping experiences. The project combines a dark editorial aesthetic with a black, off-white, and red color palette.

## Overview

The project simulates an online streetwear store, from browsing products to completing a demo checkout.

## Features

- Product catalog with category filters and sorting.
- Product detail pages with size selection and quantity controls.
- Shopping cart with item management and subtotal calculation.
- Persistent cart data using browser local storage.
- Checkout form with input validation.
- Demo order confirmation page.
- Responsive layout for desktop and mobile screens.

## Technologies

- HTML5
- Tailwind CSS v4
- JavaScript
- Browser Local Storage

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the project dependencies:

   ```bash
   npm install
   ```

4. Start the Tailwind development process using the configured script:

   ```bash
   npm run dev
   ```

5. Open `index.html` using your preferred local development server.

### How the code is organized

- **Change a price or add a product:** edit only the `products` list in `js/store.js`. Every page reads from it.
- **Display font:** change `--font-display` at the top of `src/site.css`; all headings follow.
- **Script order matters:** `motion.js` → `store.js` → `cart-drawer.js` → page script (each page already loads them in this order).
- **CSS order matters:** `output.css` → `site.css` → `motion.css`. `site.css` and `motion.css` are hand-written, so `npm run build` never overwrites them.
